Pool Glass Calculator - web app

To install on your computer and phone, put this folder on any HTTPS web host:
  Netlify Drop: open https://app.netlify.com/drop in Chrome and drag this whole "pwa" folder onto the page.
  (or GitHub Pages / your own website).
Then open the address it gives you:
  Chrome on Windows: click the install icon at the right of the address bar (or menu > Cast, save and share > Install page as app).
  Android Chrome: menu > Add to Home screen > Install.
  iPhone Safari: Share > Add to Home Screen.
After the first visit it works offline. Saved designs stay in each device's browser.

To use without installing: open index.html directly in Chrome (works offline, but cannot be installed from a file).
